# Bundled application fonts

DropSort bundles `Inter-Regular.otf` and `Inter-Bold.otf` from the official
[Inter](https://github.com/rsms/inter) 4.1 release for Latin UI text.
`Inter-OFL.txt` contains its SIL Open Font License 1.1.

Inter does not provide Arabic glyph coverage. DropSort therefore bundles
`NotoSansArabic-Regular.ttf` and `NotoSansArabic-Bold.ttf` from the official
[Noto Sans Arabic](https://github.com/notofonts/arabic) 2.013 release as the
deterministic offline Arabic companion. `NotoSansArabic-OFL.txt` contains its
SIL Open Font License 1.1.

No font is downloaded at runtime and the application does not depend on a
system-installed font.
