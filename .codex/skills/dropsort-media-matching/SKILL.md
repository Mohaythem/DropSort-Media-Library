# DropSort Media Matching

Applies to filename parsing, movie/TV detection, season/episode parsing, metadata matching, confidence scoring, ambiguous matches, review queue, subtitle and duplicate matching.

**Invariant:** low-confidence matches must never trigger automatic file movement.

This skill is defined in Phase 1 but media matching implementation is intentionally deferred until Phase 1 approval.
