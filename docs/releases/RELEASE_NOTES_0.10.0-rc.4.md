# TBD Movies 0.10.0-rc.4

إصدار تجريبي لنظام Windows x64، يجمع تحديثات الواجهة والقوائم الأخيرة.

- إعادة تصميم صفحة المسلسل ببوستر أكبر، وبيانات وأزرار مرتبة بجانبه، والمواسم أسفلهما. تبدأ المواسم مغلقة.
- أزرار صفحة المسلسل بأحجام مناسبة لمحتواها، والنبذة بمحاذاة البوستر.
- زر مفضلة واحد في صفحة الفيلم، ونقل «شاهد لاحقًا» بجانبه، وتجميع إجراءات البيانات والمطابقة والنقل إلى مسلسل.
- قوائم كليك يمين مشتركة للكروت في المكتبة والهوم والقوائم: عرض الصورة، والمفضلة، والمشاهدة لاحقًا، والقوائم المخصصة.
- عارض للصورة كاملة مع الحفاظ على نسبتها وإطار رفيع، وإغلاق بالضغط خارجها أو بمفتاح Escape.
- صف واحد لكل من إكمال المشاهدة وآخر مشاهدة والمضاف حديثًا، مع ظهور جزء من الكارت التالي عند ضيق النافذة.
- قائمتان كاملتان لإكمال المشاهدة وآخر مشاهدة، يمكن الوصول إليهما من الهوم.
- تحسين تباين الثيم الفاتح وألوان صفحة الفيلم في الثيم الداكن، وتبسيط بيانات الكروت العريضة.
- حد أدنى لحجم النافذة، واختصار Ctrl + , لفتح الإعدادات.

ملف التثبيت يعمل لكل مستخدم ويضيف اختصارًا لقائمة Start، مع خيار اختصار سطح المكتب. توجد أيضًا نسخة محمولة مضغوطة. ملفات التطبيق مستقلة وتتضمن مكتبات .NET وWindows App SDK اللازمة.

أغلق TBD Movies قبل تثبيت التحديث. بيانات المكتبة محفوظة خارج مجلد البرنامج في `%LOCALAPPDATA%\TBD Movies`؛ المثبت لا يحذف بيانات المكتبة أو ملفات الميديا.

الإصدار غير موقّع رقميًا. ما زال اختبار التثبيت على جهاز نظيف مستقل والتوافق مع مختلف الأجهزة غير منفّذ. قاعدة البيانات الحالية تستخدم الإصدار 17؛ لا تستخدم rc.2 لفتح قاعدة بيانات سبق ترقيتها.
