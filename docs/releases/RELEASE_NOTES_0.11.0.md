# DropSort 0.11.0

تحديث Windows x64 يضيف تكامل Trakt للقراءة فقط، مع تحسينات لحالات الفراغ في الواجهة.

- تسجيل الدخول باستخدام Device Code وحفظ التوكنات في مخزن Windows المحمي.
- استيراد Watchlist وقوائم Trakt المخصصة والمشاهدات وسجل المشاهدة، وعرضها في صفحة Trakt مستقلة.
- كاش منفصل لكل حساب، مع تصفح البيانات المحفوظة دون اتصال والاحتفاظ بآخر نسخة مكتملة عند فشل مورد أثناء المزامنة.
- مطابقة محلية باستخدام مُعرّفات متوافقة ونوع المحتوى. العناصر البعيدة والتعارضات تظل ظاهرة دون اختلاق ملفات محلية.
- فصل حالة المشاهدة على Trakt عن مكتبتك وقوائمك وسجل المشاهدة المحلي. لا توجد كتابة إلى Trakt أو scrobbling أو مزامنة ثنائية.
- إصلاح الإلغاء وإعادة الاتصال، وتحميل القوائم، وقيم JSON الفارغة، ورفض التوكنات وحالات التزامن.
- إصلاح زر فتح إعدادات Trakt في حالة الفراغ، وضبط حالتي Continue Watching وRecently Watched على ارتفاع الكارت المعتاد.

## إعداد Trakt

من Settings → Trakt، أدخل Client ID العام وعنوان HTTPS Redirect URI المسجلين لتطبيق Trakt الخاص بك. لا تدخل Client Secret. اضغط Connect واتبع كود التحقق، ثم Sync Now. لا يتضمن الإصدار حسابًا أو بيانات اعتماد أو بيانات تجريبية.

## التنزيل والترقية

حمّل `DropSortSetup.exe` للتثبيت لكل مستخدم، أو فك ضغط `DropSort-0.11.0-win-x64.zip` بالكامل وشغّل `DropSort.UI.exe`. الحزمة تتضمن .NET وWindows App SDK.

أغلق DropSort قبل التحديث. بيانات المكتبة تظل في `%LOCALAPPDATA%\DropSort` خارج مجلد تثبيت التطبيق. يضيف الإصدار ترقية قاعدة بيانات إلى المخطط 18 لكاش Trakt؛ لا تفتح القاعدة بعد ترقيتها بإصدار أقدم لا يدعم هذا المخطط.

## التحقق والحدود

نجح آخر تشغيل أوسع للاختبارات: 973 اختبارًا، مع استبعاد اختبارات مخزن بيانات اعتماد TMDB الأصلي. ونجحت 25 حالة Home بعد تعديل ارتفاع الفراغ. نتائج التحقق من مصدر الإصدار والحزمة النهائية مرفقة في `VERIFICATION.md` و`BUILD_MANIFEST.json`.

تسجيل الدخول بحساب Trakt حقيقي وحفظ بيانات اعتماده لم يُختبرا عمليًا. الحزمة غير موقعة رقميًا. اختبار التثبيت والترقية والإزالة على جهاز نظيف غير منفذ. التحقق من الواجهة يدوي بواسطة المستخدم؛ لم تُجر أتمتة للواجهة.
