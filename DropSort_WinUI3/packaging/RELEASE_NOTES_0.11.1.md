# DropSort 0.11.1

تحديث شامل يتضمن حزمة التحسينات البصرية للنظام الموحد (UI Kit)، وتكامل Trakt المحمي، ومعالجة ثبات وسلاسة مواسم وحلقات المسلسلات ومطابقة القوائم.

### أبرز التحسينات والمميزات:

- **نظام التصميم الموحد (UI Kit Modernization)**:
  - تطبيق شبكة الأبعاد القياسية (8pt Grid System) على بطاقات وأزرار شاشات التفاصيل.
  - شارات دلالية موحدة (`StatusPillStyle`) للمعلومات الوصفية (سنة الإنتاج، المدة، تقييم TMDB، الدقة).
  - ضبط استجابة ومحاذاة الشاشات لدعم واجهة اللغة العربية (RTL) بسلاسة كاملة.
  - استعادة وتوحيد مبدل نمط العرض (Grid / List Switcher) بحواف وأبعاد هندسية دقيقة.

- **استقرار مواسم وحلقات المسلسلات (`TVShowDetailsPage`)**:
  - الحفاظ التلقائي على حالة المواسم المفتوحة (`IsExpanded`) عند تحديد الحلقات كمشاهدة لمنع انغلاقها المفاجئ.
  - إمكانية التبديل الحر بين تحديد الحلقة كمشاهدة أو إلغاء المشاهدة (`Unmark Watched`) مع تحديث فوري لشريط تقدم الموسم.
  - تحسين استجابة التمرير وأداء فتح وإغلاق المواسم الطويلة والقضاء على التجميد والتعليق (Lag).
  - فحص صامت وتلقائي في الخلفية لحالة الملفات المفقودة وتحديث الواجهة دون أي تعطيل للمستخدم.

- **الحفظ الآمن لبيانات Trakt و TMDB**:
  - تخزين واسترجاع بيانات الاعتماد والتوكنات بشكل آمن ودائم عبر Windows Data Protection API (DPAPI).
  - حماية الجلسة وضمان عدم طلب تسجيل الدخول مجدداً بعد إغلاق التطبيق.
  - استبعاد الأفلام والمسلسلات الموجودة بالفعل داخل القائمة عند اختيار إضافة عناصر جديدة.
  - إضافة زر مزامنة شامل لكافة القوائم في شريط التحكم العلوي.

---

### التنزيل والترقية:

- **مثبت الإعداد (Installer)**: حمّل `DropSortSetup.exe` للتثبيت المباشر لحساب المستخدم (لا يتطلب صلاحيات مسؤول).
- **النسخة المحمولة (Portable)**: فك ضغط `DropSort-0.11.1-win-x64.zip` في أي مجلد وشغّل `DropSort.UI.exe` مباشرة.
- الحزمة قائمة بذاتها بالكامل وتتضمن بيئة تشغيل .NET 10 و Windows App SDK 1.7.
- بيانات المكتبة وقاعدة البيانات الشخصية محفوظة بشكل آمن ومستقل في مسار:
  `%LOCALAPPDATA%\DropSort`
